> 주: R24는 별도 F로 유지하지 않고 F22·F23의 결과 항목에 통합했다(팀·오케스트레이터 합의). 기존 F24(과거 기록 목록)·F25(지도)·F26(PR)·F27(목표 달성)은 이번 갱신에서 F24\~F27로 번호가 한 칸씩 당겨졌다. **이 재정렬은 "번호는 절대 재정렬하지 않는다" 규칙이 공식화되기 이전(05-policy.md 작성 전)에 있었던 예외이며, 되돌리지 않고 그대로 둔다. 이후로는 항목이 빠져도 번호를 유지하고 빈 번호로 남긴다 (예: F10).**
> 주: (기록용, 현재는 후순위) F4(목표 변경)는 팀 요청으로 트리거를 "프로필 화면"에서 "러닝 시작 화면"으로 옮겼다(프로필까지 들어가는 번거로움 제거 목적). F3(러닝 시작 시 저장된 목표 자동 불러오기)와 F4(러닝 시작 화면에서 목표 변경)는 같은 화면에서 이어지는 동작이지만, R3(자동 불러오기)와 R4(사용자가 직접 변경)의 트리거·입력·결과가 서로 달라 하나로 합치지 않고 별도 F로 유지했었다. F4의 UI는 러닝 시작 화면(S1)의 톱니바퀴 아이콘 → 팝업으로 구체화되어 있었다. 이 각주는 F1\~F4가 후순위 전환되기 전의 논의 기록이며, 목표 개념이 부활하면 참고할 수 있도록 남겨둔다.
> 주: F10은 팀 결정으로 제거되었다(음성 페이스 안내 기능 제외). 05-policy.md의 P행들이 F5·F6·F8·F9·F11·F12 등 F 번호를 직접 참조하고 있어 번호는 재정렬하지 않고 빈 번호로 남겨둔다.
> 주: F29는 세 차례 재정의를 거쳐 팀이 최종 확인했다 — ①"목표 미달성 종료 확인 메시지" → ②(이전 라운드, 팀 확인 전 임시 해석) "결과 화면에 개인 순위만 표시" → ③(이번, 팀 확정) "총 거리·탄천 인정 거리·개인 순위·러닝 시간·페이스 5항목을 모두 표시하는 결과 화면 단일 기능"으로 구체화되었다. F12(총 거리)·F13(탄천 인정 거리)·F14(시간)·F15·F16(주간·월간 순위 변화, 이미 후순위)·F31(페이스)이 모두 F29로 통합되었다.
> 주: F19는 "탄천 Ranking Zone 누적 거리 기준 전체 순위 리스트"로 단순화되며 TOP100 캡 개념이 빠졌다. F17·F18(주간·월간 랭킹 화면)·F20(TOP100 밖 별도 표시)·F27(목표 달성 여부)은 02의 MVP 재축소에 맞춰 후순위 전환되었다.
> 주: F22·F23(지난주·지난달 기록 비교)·F25(러닝 경로 지도)는 팀 결정으로 후순위 전환되었다. F30(닉네임)은 "자동 랜덤 생성" 로직만 빠지고 "직접 입력(필수)"만 남았다.
