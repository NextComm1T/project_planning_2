## 상태값

- **러닝 세션**: 시작 전 → 진행 중 → 종료 · 전이 조건: "러닝 시작" 버튼 클릭 + GPS 정상 확인 시 시작 전→진행 중, 사용자가 "종료" 버튼을 직접 클릭 시 진행 중→종료 (자동 종료·일시정지는 MVP 미지원 — 00-backlog.md 참고)
- **GPS 신호**: 정상 → 끊김 → 복구(정상) · 전이 조건: 신호 유실 시 정상→끊김, 신호 재획득 시 끊김→복구(정상 상태로 합류)
- **랭킹 집계**: 집계 중 (단일 상태, 초기화 없이 누적) — 주간·월간 구분이 후순위로 빠지면서 별도 마감·초기화 전이 없이 계속 누적되는 단일 집계로 단순화됨
- **계정**: 미가입 → 가입 중(소셜 인증 완료 · 닉네임 미설정) → 가입 완료 → 탈퇴 · 전이 조건: 소셜 로그인 첫 인증 성공 시 미가입→가입 중(UID 발급), 유효한 닉네임 저장 시 가입 중→가입 완료, 탈퇴 확인 시 가입 완료→탈퇴(계정과 기록을 즉시 삭제 — 되돌릴 수 없음) · P11·P13
- **로그인**: 로그아웃 ↔ 로그인 · 전이 조건: 소셜 로그인 인증 성공 시 로그아웃→로그인, 설정 화면에서 로그아웃 선택 시(F12) 로그인→로그아웃. 앱을 다시 열어도 로그인 상태는 유지된다 · R24

## 서비스 정책

| SP1 | 서비스는 다른 사용자의 프로필이나 상세 정보를 조회하는 기능을 제공하지 않는다. 러닝 시작 전·러닝 중·결과 화면·기록 상세 지도(F1·F2·F9·F11)에도 본인의 위치·GPS 이동 경로만 표시하며, 다른 사용자의 실시간 위치나 저장된 경로는 노출하지 않는다. (01-problem.md MVP 개발 제약 사항 재확인) |

| SP3 | **수집 범위** — 서비스가 사용자에게서 수집하는 값은 **소셜 로그인 제공자 · 소셜 계정 식별자 · 닉네임 · 러닝 기록**으로 한정한다. 러닝 기록에는 수치와 GPS 이동 경로, 그리고 그 세션에서 파생되는 값(종료 타임스탬프 · 결과 화면에 표시한 순위 · 개인 최고 기록 갱신 여부 · 지점별 Zone 내부 여부 · 거리 계산 제외 여부)이 포함된다. 사용자 화면에 표시하지 않는 운영·식별용 값에는 **사용자 UID와 가입 일시**, 그리고 세션·랭킹 집계·개인 최고 기록이 내부적으로 갖는 상태·시각 값(세션 상태·종료 타임스탬프·집계 상태·최초 달성 시각 등)이 포함된다. 어떤 칸을 실제로 두는지는 06-data.md 「저장 항목」이 단일 기준이며, 이 정책을 고칠 때 그 표를 함께 본다. **삭제** — 회원 탈퇴하면 위 수집·운영 값은 모두 즉시 삭제된다 · P13. **공개 범위** — 본인 외에 공개하는 값은 **닉네임과 탄천 Ranking Zone 인정 누적 거리, 그리고 그 값으로 산정한 순위**뿐이고, 그 외 프로필·러닝 세션·개인 최고 기록·GPS 이동 경로는 본인만 조회할 수 있다 · P5·P6·SP1.
