## 상태값

- **러닝 세션**: 시작 전 → 진행 중 → 종료 · 전이 조건: "러닝 시작" 버튼 클릭 + GPS 정상 확인 시 시작 전→진행 중, 사용자가 "종료" 버튼을 직접 클릭 시 진행 중→종료 (자동 종료·일시정지는 MVP 미지원 — 02-workflow.md 후순위 표 참고)
- **GPS 신호**: 정상 → 끊김 → 복구(정상) · 전이 조건: 신호 유실 시 정상→끊김, 신호 재획득 시 끊김→복구(정상 상태로 합류)
- **주간 랭킹 집계**: 집계 중 → 마감 → 새 주 집계 시작 · 전이 조건: 매주 월요일 00:00 도달 시 자동으로 마감 후 새 주 집계 시작 (팀 원문 확정)
- **월간 랭킹 집계**: 집계 중 → 마감 → 새 달 집계 시작 · 전이 조건: 매월 1일 00:00 도달 시 자동으로 마감 후 새 달 집계 시작 (팀 원문 확정)
