## 상태값

- **러닝 세션**: 시작 전 → 진행 중 → 종료 · 전이 조건: GPS 확인이 완료된 상태(P1)에서 "러닝 시작" 버튼을 클릭하면 3초 카운트다운이 시작되고, **카운트다운이 끝나는 순간** 시작 전→진행 중으로 전이한다 · R16·F1(팀 확정 2026-09-11 9차 — 러닝 시간도 이 순간부터 잰다). **카운트다운 도중에는 취소할 수 있고, 취소하면 세션은 "시작 전"에 그대로 머문다.** 사용자가 "종료" 버튼을 직접 클릭 시 진행 중→종료 (자동 종료·일시정지는 MVP 미지원 — 00-backlog.md 참고). **이 전이는 종료 버튼을 누른 시점에 일어나며 저장·순위 계산의 성공 여부와 무관하다** — 종료 처리가 실패해도 세션은 "종료"로 남고 저장만 다시 시도한다(그래야 결과 화면에 들어갈 수 있고 · P4, "진행 중" 세션을 전제로 하는 P7·P12 에 걸리지 않는다) · P14. **화면이 꺼지거나 다른 앱으로 전환된 동안(앱이 닫힌 것은 아닌 상태)에도 측정은 그대로 계속되며 그 구간도 거리·경로에 포함한다**(팀 확정 2026-09-11 9차). 앱이 완전히 종료됐다가 다시 열려도 "진행 중" 세션은 종료되지 않고 러닝 진행 화면으로 돌아와 이어진다 — **앱이 완전히 닫혀 있던 동안만** P2의 GPS 끊김 구간과 같이 거리·경로에서 제외한다
- **GPS 신호**: 정상 → 끊김 → 복구(정상) · 전이 조건: 신호 유실 시 정상→끊김, 신호 재획득 시 끊김→복구(정상 상태로 합류). **「신호 없음」과 「끊김」은 같은 상태를 가리키는 같은 말이며, 문서·화면 문구 모두 「끊김」으로 통일한다**(팀 확정 2026-09-11 9차). 끊긴 즉시 거리·경로 제외가 적용되고(P2), 끊김이 2초 이상 지속되면 화면 경고를 띄운다(P3)
- **랭킹 집계**: 집계 중 (단일 상태, 초기화 없이 누적) — 주간·월간 구분이 후순위로 빠지면서 별도 마감·초기화 전이 없이 계속 누적되는 단일 집계로 단순화됨
- **계정**: 미가입 → 가입 중(소셜 인증 완료 · 닉네임 미설정) → 가입 완료 → 탈퇴 · 전이 조건: 소셜 로그인 첫 인증 성공 시 미가입→가입 중(UID 발급), 유효한 닉네임 저장 시 가입 중→가입 완료, 탈퇴 확인 시 가입 완료→탈퇴(계정과 기록을 즉시 삭제 — 되돌릴 수 없음) · P11·P13
- **로그인**: 로그아웃 ↔ 로그인 · 전이 조건: 소셜 로그인 인증 성공 시 로그아웃→로그인, 설정 화면에서 로그아웃 선택 시(F12) 또는 탈퇴 확인 시(F13 — 계정 삭제와 함께) 로그인→로그아웃. 앱을 다시 열어도 로그인 상태는 유지된다 · R24
