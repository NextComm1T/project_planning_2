## 상태값

- **러닝 세션**: 시작 전 → 진행 중 → 종료 · 전이 조건: "러닝 시작" 버튼 클릭 + GPS 정상 확인 시 시작 전→진행 중, 사용자가 "종료" 버튼을 직접 클릭 시 진행 중→종료 (자동 종료·일시정지는 MVP 미지원 — 02-workflow.md 「검토했으나 제외」 표 참고)
- **GPS 신호**: 정상 → 끊김 → 복구(정상) · 전이 조건: 신호 유실 시 정상→끊김, 신호 재획득 시 끊김→복구(정상 상태로 합류)
- **랭킹 집계**: 집계 중 (단일 상태, 초기화 없이 누적) — 주간·월간 구분이 후순위로 빠지면서 별도 마감·초기화 전이 없이 계속 누적되는 단일 집계로 단순화됨 (주간·월간 집계의 상세 전이 조건은 상태값 목록에서 제거 — 「검토했으나 제외」 표 참고)
