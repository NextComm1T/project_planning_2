### 정리 이력

> S0의 To-Be에 닉네임 설정 흐름을 추가했다 — 03-requirements.md R15(구 R33)·04-features.md F10(구 F30) 신설에 따른 반영(팀 확정 내용 그대로). 이후 "자동 랜덤 생성" 부분은 후순위 전환되어 "가입 시 직접 설정(필수)"만 남도록 다시 단순화했다.
> S4의 "평균 페이스", S6의 "지난주·지난달 비교"는 후순위 전환되어 To-Be 문구와 mermaid에서 제거했다.
> A2(관리진)는 팀 결정으로 제거되었다 — "A2의 역할이 MVP 시점에 중요하지 않아 빼도 괜찮다." 04-features.md F2(구 F8, 실시간 표시에 병합됨), 05-policy.md 구P8·구SP5가 A2를 참조하고 있어 해당 문서에서도 함께 정리했다.
> 팀의 MVP 재축소 결정으로 목표 거리·시간 설정(S0)·종료 확인 메시지(S3)·주간·월간 랭킹 구분(S4·S5)까지 후순위로 뺐다. 이후 A1 행위자 설명·S5 To-Be에 남아있던 "주간·월간" 언급과, S0·S2·S3의 As-Is/감정/불편 칸에 남아있던 "목표" 프레이밍도 별도로 마저 정리했다(둘 다 사용자가 직접 지적해 잡은 잔여 불일치).
> 03-requirements.md가 R1~R16(이후 R17 추가)으로, 04-features.md가 F1~F13→F1~F10으로 재정렬되면서 이 문서 각주의 R33·F30·F8 참조를 R15(구 R33)·F10(구 F30)·F2(구 F8)로 갱신했다.
> S1의 GPS 확인 순서를 바꿨다 — 기존엔 "버튼 클릭 → 카운트다운 중 GPS 확인"이었는데, 네트워크가 불안정하면 카운트다운이 끝나고서야 실패를 알게 되는 문제가 있어 "GPS 확인 완료 → 버튼 활성화 → 클릭 → 카운트다운(순수 준비 신호)"으로 바꿨다. 05-policy.md P1은 이 순서 변경과 이미 일치해 따로 고치지 않았다. S2에는 R17(페이스 실시간 확인) 신설에 맞춰 페이스를 추가했다.
