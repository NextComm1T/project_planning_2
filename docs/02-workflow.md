## 흐름
S1 → S2 → S3 → S4 → S5 · 분기: 러닝 중(S2~S3 사이) GPS 신호가 끊기거나 부정확해지면 유저에게 "GPS 신호 약함" 경고를 화면에 띄움. 신호가 끊긴 구간은 끊기기 직전/직후 위치를 이어서 대략 보간(추정)하여 거리 계산에 포함함 — 이유: 끊긴 동안 실제로 멈췄는지 계속 달렸는지 애매한데 무조건 제외하면 실제로 달린 거리가 기록에서 누락돼 유저가 억울함을 느낄 수 있음
