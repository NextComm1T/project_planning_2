- **근거**: `탄천런.dc.html` L921-934 의 `<nav>` 가 `grid-template-columns:1fr 1fr 1fr` 로 3칸이다.

## 6. 로그인 실패 안내를 URL 쿼리로 표현 (구현 방식 메모)

- **문서**: `docs/04-features.md:23` F8 예외 — "인증 실패 또는 취소 시 로그인 실패 안내 표시". 표현 방식은 규정하지 않는다.
- **구현**: `/login?error=cancelled` · `/login?error=failed`. OAuth 콜백이 실패를 돌려주는 방식 그대로라 나중에 연동할 때 그대로 이어진다. 알 수 없는 값은 일반 실패 문구로 묶어 원인 코드를 사용자에게 그대로 보이지 않는다.
- **문서 변경**: 불필요.

## 8. `/` 는 로그인 화면으로 보낸다 (분기 미구현)

- **문서**: `docs/07-screens.md:35-38` — 앱 실행 시 첫 화면은 로그인 상태 · 계정 상태 · 진행 중 세션에 따라 4갈래로 갈린다.

  | 상태 | 첫 화면 |
  | --- | --- |
  | 로그아웃 | 로그인 화면 |
  | 진행 중 세션 있음 | 러닝 진행 화면(이어서 측정) |
  | 가입 중 | 닉네임 설정 화면 |
  | 가입 완료 + 세션 없음 | 러닝 시작 화면 |

- **구현**: 인증이 아직 없어 **항상 로그아웃으로 보고 `/login` 으로 redirect** 한다. 네 갈래 중 첫 줄만 구현된 상태다.
- **채울 시점**: 인증이 붙으면 `src/app/page.tsx` 의 redirect 자리가 그대로 분기점이 되고, "가입 완료 + 세션 없음" 일 때 이 자리에서 러닝 시작 화면(F1)을 그린다.
- **문서 변경**: 불필요.
