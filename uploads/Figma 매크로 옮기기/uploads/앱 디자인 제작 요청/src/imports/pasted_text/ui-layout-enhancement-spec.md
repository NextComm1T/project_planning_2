현재 만들어진 홈(러닝 시작), 러닝 진행, 내 기록 화면의
기능과 Visual Style은 유지하고 **레이아웃과 가독성을 크게 개선**해줘.

현재 문제는 콘텐츠가 화면 상단에 작게 몰려 있고
화면 하단에 사용되지 않는 빈 공간이 너무 많다는 것이다.

이번 수정에서는 단순히 Container 크기만 키우지 말고,
**실제 내부 콘텐츠, 지도, 숫자, 버튼까지 함께 확대하여
모바일 화면의 사용 가능한 세로 공간을 적극적으로 채워줘.**

새로운 기능을 임의로 추가하지 말고 아래 3개 화면만 수정해줘.


# 1. 홈 / 러닝 시작 화면

현재 홈 화면의 구성과 순서는 유지한다.

- Header
- 사용자 인사
- 탄천 Ranking Zone 지도
- 내 탄천 순위
- 러닝 시작하기
- Bottom Navigation

어떤 요소도 삭제하지 마.

현재 문제는 지도와 러닝 시작 버튼 아래에
사용되지 않는 빈 공간이 너무 많이 남는다는 것이다.

## 지도 확대

“탄천 Ranking Zone” 지도 카드를 현재보다 더 크게 만들어줘.

중요:
Card Container만 키우지 말고
**실제 Map Content 자체가 확대된 카드 전체 영역을 채우게 해줘.**

지도 Header 아래부터 지도 카드 하단까지
빈 흰색 공간 없이 실제 지도가 꽉 차야 한다.

지도에서는 다음이 충분히 크게 보여야 한다.

- 탄천
- Ranking Zone
- 현재 위치
- 확대 / 축소 버튼
- 현재 위치 버튼
- Legend

Ranking Zone은 탄천을 따라 이어지는 영역으로 유지한다.

## 내 탄천 순위

현재 “내 탄천 순위” 카드는 유지한다.

- 5위 / 14명
- 탄천 누적 거리 61.0km

정보의 글씨와 숫자를 현재보다 조금 키워
빠르게 읽을 수 있게 한다.

단, 지도보다 시각적으로 강하게 만들지는 않는다.

## 러닝 시작 버튼

현재 “러닝 시작하기” 버튼을
**가로뿐 아니라 세로 높이도 더 크게** 만들어줘.

버튼은 엄지로 쉽게 누를 수 있는
홈 화면의 가장 명확한 Primary CTA여야 한다.

버튼 텍스트와 아이콘도 함께 확대한다.

단순히 버튼 주변 Padding만 늘리지 말고
실제 Button Component의 height와 label 크기를 키워줘.

지도 + 순위 카드 + 러닝 시작 버튼이
Bottom Navigation 바로 위까지 자연스럽게 공간을 사용하도록
전체 세로 간격을 다시 배분해줘.

불필요한 큰 빈 공간을 남기지 마.


# 2. 러닝 진행 화면 전체 재구성

현재 러닝 진행 화면은
러닝 시간의 중요도가 충분히 드러나지 않고,
지도와 핵심 데이터가 화면 크기에 비해 작으며,
러닝 종료 버튼 위에 너무 큰 빈 공간이 있다.

이 화면은 달리는 중 한눈에 정보를 확인해야 하므로
**가독성을 가장 우선하여 다시 배치**해줘.

화면 순서는 다음으로 구성해줘.

1. 러닝 시간 + GPS 상태
2. 큰 실시간 지도
3. 총 거리 / 탄천 인정 / 현재 페이스
4. 러닝 종료 버튼

불필요한 빈 공간을 최소화해서
화면 전체를 적극적으로 사용해줘.


# 3. 러닝 시간을 최상위 핵심 데이터로 강조

현재 상단의 “러닝 시간 00:04”가
상단에 너무 붙어 있고 시각적으로 잘 보이지 않는다.

러닝 시간을 화면의 주요 데이터 중 하나로
명확하게 강조해줘.

예:

러닝 시간

00:04

“러닝 시간” Label은 작고 명확하게,
“00:04” 숫자는 훨씬 크고 굵게 표시한다.

00:04가 Dynamic Island나 Status Bar와
시각적으로 겹쳐 보이지 않도록
충분한 Safe Area와 여백을 확보한다.

GPS 상태는 러닝 시간과 경쟁하지 않도록
오른쪽에 작은 Status Chip으로 유지한다.

예:

                    ● GPS 정상
러닝 시간
00:04

또는 화면 폭에 맞는 자연스러운 구조로 조정해줘.


# 4. 러닝 중 지도 대폭 확대

러닝 중 지도는 현재보다 더 크게 만들어줘.

단순히 Map Container를 확대하는 것이 아니라
**실제 Map Content도 Container 전체를 채우도록 확대한다.**

러닝 중 지도는 화면에서
러닝 시간 다음으로 큰 시각적 영역이 되도록 한다.

지도에는 기존대로

- 탄천
- Ranking Zone
- 현재 위치
- 지금까지 달린 Route
- Zoom + / -
- 현재 위치 버튼

을 표시한다.

사용자가 실제로 뛰면서
“내가 지금 어디에 있는가”를 빠르게 확인할 수 있는 크기로 만든다.


# 5. 러닝 데이터 카드 재구성

지도 아래에는 현재처럼 데이터를 여러 개의 큰 카드로
분리하지 말고 하나의 넓은 Summary Card 안에

총 거리 | 탄천 인정 | 현재 페이스

3개를 나란히 보여줘.

예:

┌─────────────────────────────────┐
│ 총 거리       탄천 인정      현재 페이스 │
│ 0.01 km      0.00 km       --'--" /km │
└─────────────────────────────────┘

각 숫자는 현재보다 크게 만들어
달리는 중 빠르게 읽을 수 있게 해줘.

“탄천 인정”은 현재 앱의 Soft Green Accent를 유지할 수 있다.

숫자와 단위의 크기 차이를 명확히 하여
숫자가 가장 먼저 보이도록 한다.


# 6. 러닝 종료 버튼 확대

현재 화면 하단의 “러닝 종료” 버튼을
**현재보다 더 크고 누르기 쉽게 만들어줘.**

가로 폭을 충분히 사용하고
버튼의 세로 높이와 텍스트 크기도 확대한다.

러닝 중 실수로 누르기 어려우면서도
필요할 때 바로 찾을 수 있는 크기로 만든다.

버튼은 화면 하단 Safe Area 위에 고정한다.

지도와 데이터 영역을 확대하면서도
러닝 종료 버튼은 항상 화면에 보여야 한다.

종료 버튼 위에 현재처럼
큰 빈 공간을 남기지 마.

콘텐츠가

러닝 시간
↓
큰 지도
↓
러닝 데이터
↓
적절한 여백
↓
큰 러닝 종료 버튼

순서로 화면 전체를 균형 있게 채우도록 해줘.


# 7. GPS 신호 끊김 시뮬레이션 유지

현재 만들어진 “GPS 신호 끊기 시뮬레이션” 기능은 유지한다.

GPS 신호가 끊기면 기존 정책대로

- “GPS 신호가 약합니다” 경고
- 현재 위치 확인 중 상태
- 총 거리 증가 중단
- 탄천 인정 거리 증가 중단
- Route 기록 중단
- 현재 페이스 계산 불가

상태를 보여준다.

러닝 시간은 계속 진행한다.

GPS 신호가 복구되면 복구 위치부터
다시 Route와 거리를 측정하는 기존 동작을 유지한다.


# 8. 내 기록 화면 전체 가독성 확대

현재 “내 기록” 화면은
정보가 전체적으로 너무 작고 한 화면에 많은 기록을 보여주려고 해서
가독성이 떨어진다.

**한 화면에 최대한 많은 기록을 보여주는 것보다
각 기록을 쉽게 읽고 누를 수 있는 것을 우선해줘.**

현재 디자인 스타일은 유지하면서

- Page Title
- Section Title
- 숫자
- Label
- 기록 Row 높이
- 기록 사이 여백
- 터치 영역

을 전체적으로 확대해줘.

한 화면에 보이는 기록 개수가 줄어들어도 괜찮다.
아래 기록은 Scroll하여 확인하도록 한다.


# 9. 내 기록 상단에 누적 거리 영역 추가

개인 최고 기록(PR) 카드 위에
새로운 **누적 러닝 요약 영역**을 추가해줘.

두 개의 큰 카드를 가로로 나란히 배치한다.

왼쪽:

총 누적 거리
37.6 km

오른쪽:

탄천 인정 누적 거리
27.4 km

위 숫자는 현재 화면을 확인하기 위한 예시 데이터로 사용해도 된다.

두 카드 모두 숫자를 크게 보여주되,
탄천 인정 누적 거리는 Soft Green Accent를 사용해서
탄천 관련 데이터임을 자연스럽게 구분해줘.

구조:

내 기록
개인 최고 기록 및 러닝 히스토리

누적 러닝
┌──────────────┐ ┌──────────────┐
│ 총 누적 거리   │ │ 탄천 인정 누적 거리 │
│   37.6 km     │ │     27.4 km       │
└──────────────┘ └──────────────┘

개인 최고 기록
┌────────┐ ┌────────┐ ┌────────┐
│ 최장 거리 │ │ 최고 페이스 │ │ 최대 시간 │
│ 10.1km  │ │ 5'08"   │ │ 52:22   │
└────────┘ └────────┘ └────────┘

러닝 기록
...


# 10. PR 카드 확대

기존 PR 카드 3개는 삭제하지 않는다.

- 최장 거리
- 최고 페이스
- 최대 시간

3개의 구조를 유지하되
현재보다 Card Height, 숫자, Label을 전체적으로 확대해줘.

PR 값이 카드에서 가장 먼저 보이게 하고
단위는 값보다 작게 표현한다.


# 11. 러닝 기록 목록 확대

현재 러닝 기록 목록의 각 Row가 너무 작고
한 줄에 정보가 과도하게 압축되어 있다.

각 러닝 기록 Row의 높이를 늘려줘.

일자는 현재보다 크게 표시하고,
그 아래에

총 거리
탄천 인정
시간
평균 페이스

를 읽기 쉽게 배치한다.

각 숫자도 현재보다 크게 표시한다.

탄천 인정 거리는 현재처럼
Soft Green Accent를 사용할 수 있다.

오른쪽의 > Chevron은 유지하여
해당 기록을 눌러 상세 기록으로 이동할 수 있음을 보여준다.

각 Row 전체를 터치 가능한 영역으로 만든다.

한 화면에 모든 기록을 억지로 보여주지 마.
스크롤 가능한 목록으로 구성한다.


# 12. 내 기록 화면 정보 계층

내 기록 화면의 시각적 우선순위는 다음과 같이 한다.

1. 내 기록 Title
2. 총 누적 거리 / 탄천 인정 누적 거리
3. 개인 최고 기록(PR)
4. 과거 러닝 기록

모든 숫자와 텍스트가 현재보다 쉽게 읽히도록
전체 Typography Scale을 한 단계 키워줘.


# 13. 공통 레이아웃 원칙

세 화면 모두 현재 iPhone 화면 안에서
콘텐츠가 너무 작게 위쪽에 몰리지 않도록 한다.

**사용 가능한 화면 공간을 적극적으로 사용해줘.**

특히 다음 원칙을 지켜줘.

- Container만 확대하고 내부 콘텐츠를 그대로 두지 않는다.
- Map Container 확대 시 실제 Map도 같이 확대한다.
- Button 확대 시 실제 Button Height와 Text도 확대한다.
- Card 확대 시 내부 숫자와 Label도 함께 확대한다.
- 불필요한 빈 공간을 최소화한다.
- 터치 가능한 요소는 충분히 크게 만든다.
- 중요한 숫자는 작은 설명 Text보다 확실히 크게 표현한다.
- Status Bar / Dynamic Island / Bottom Safe Area와 겹치지 않는다.
- 화면이 길어지면 억지로 축소하지 말고 Scroll을 사용한다.

현재의 Warm Minimal / Friendly Local Running
Visual Style은 그대로 유지한다.

전체 UI를 새롭게 디자인하지 말고
현재 만들어진 디자인을 기반으로
**크기, 가독성, 공간 활용만 개선해줘.**


# 14. 절대 삭제하지 않을 요소

홈:
- GPS 준비완료
- 설정 버튼
- 탄천 Ranking Zone 지도
- 내 탄천 순위
- 탄천 누적 거리
- 러닝 시작하기
- Bottom Navigation

러닝 중:
- 러닝 시간
- GPS 상태
- 지도
- 총 거리
- 탄천 인정 거리
- 현재 페이스
- 러닝 종료

내 기록:
- 설정 버튼
- 개인 최고 기록 3개
- 러닝 기록 목록
- 기록 상세 진입

위 요소는 반드시 유지하고,
이번에 추가하는

- 총 누적 거리
- 탄천 인정 누적 거리

2개 카드도 내 기록 화면에 포함해줘.
